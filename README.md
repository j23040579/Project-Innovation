# Project Innovation — Typhoon weather profiles

Open [`Typhoon/training/train_typhoon_models.ipynb`](Typhoon/training/train_typhoon_models.ipynb) and run its cells from top to bottom. It trains directly from historical weather in the three days before confirmed landfall. No coordinate reconstruction or nearest-prefecture model is required.

See [Typhoon/README.md](Typhoon/README.md) for paths and outputs. Install `requirements.txt` in a Python 3.12 notebook environment.
